# Snakemake FastQC Pipeline

A reproducible bioinformatics workflow for sequencing read quality
control using Snakemake, FastQC, and MultiQC.

## Objectives

- Automate quality control of FASTQ files.
- Support single-end and paired-end sequencing data.
- Manage software dependencies using Conda.
- Provide configurable input and output paths.
- Implement automated workflow testing using GitHub Actions.

## Development Environment

- WSL2 / Ubuntu
- Visual Studio Code
- Snakemake 9.27.2
- Python 3.12
- Conda
- Git and GitHub
